# TIG-Generated Cloq proofs

Timing proofs generated by TIG's Cloq backend for RISC-V examples in `Picinae/timing/examples`.

To generate:

```bash
GHIDRA_HOME=/path/to/ghidra python -m tig.cloq_main <elf file> \
                                   --header-from HAND_PROOF.v \
                                   --out tig_FUNC.v
```

- `HAND_PROOF.v`: the hand-written proof, which supplies the imports and the
  `binary` definition.
